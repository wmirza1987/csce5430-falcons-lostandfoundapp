# UI/UX Design Notes

## Lost and Found for Campus --- Team Falcons

**Owner:** Sai Sathvika Potluri --- Design Lead & Documentation Lead

## Design Goal

Create a simple interface for students, faculty, staff, and campus
administrators with minimal technical knowledge.

## Primary User Flow

1.  Login.
2.  Create a Lost or Found listing with category, description, location,
    date, and photo.
3.  Search listings or receive a potential match.
4.  Submit identifying details for a claim.
5.  Poster approves or rejects the claim.
6.  Approved users coordinate the handoff through messaging.
7.  Mark the item Resolved after return.

## Main Screens

-   Login / Registration
-   Active Listings
-   Create Listing
-   Search and Filters
-   Listing Details / Potential Matches
-   Claim Verification
-   Messaging
-   Campus Map
-   Admin Dashboard

## Design Principles

-   Minimize steps and manual data entry.
-   Use clear status labels: Active, Claim Pending, Resolved, Archived.
-   Support desktop and mobile browsers.
-   Routine administration should not require database or coding
    knowledge.
