# Admin Dashboard Requirements

## Lost and Found for Campus --- Team Falcons

## Purpose

Allow authorized campus staff to manage lost-and-found activity without
programming or database knowledge.

## Core Functions

-   View, search, and filter listings.
-   Review active, unresolved, resolved, and archived items.
-   Change listing status and archive old records.
-   Reopen a listing resolved by mistake.
-   Review claims and reported messages.
-   View basic analytics such as resolution rate, common categories, and
    hotspot locations.

## Usability

Common tasks should use clear forms and buttons with minimal manual data
entry.

## Maintenance Roles

**Operational maintenance:** Campus staff manage listings, claims,
statuses, and archived records.

**Technical maintenance:** A technical administrator/developer handles
deployment, database configuration, integrations, backups, and software
updates.

## Proposed Listing Lifecycle

Active → Potential Match → Claim Pending → Resolved → Archived
