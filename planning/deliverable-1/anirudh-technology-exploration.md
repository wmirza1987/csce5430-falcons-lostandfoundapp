# Technology Exploration — Venkata Sai Anirudh Naidu Mamidi

## Assigned Technology Options

### React + Node.js/Express (MERN-style)

**Advantages**
- The team already has some JavaScript experience.
- A single language can be used across the front end and back end.
- Large ecosystem and community support.
- Fast to prototype.

**Concerns**
- Less structure/opinionation than a full framework.
- The team must agree on conventions.
- Asynchronous JavaScript can be difficult for teammates newer to the language.

### Java Spring Boot + Angular

**Advantages**
- Strong typing can catch errors early.
- Aligns with enterprise-style software engineering practices.
- Suitable for teams with Java experience.

**Concerns**
- Steeper learning curve.
- More boilerplate.
- Slower to iterate during a short course timeline.

## My Evaluation Focus

As Backend Implementation Lead, Configuration Management Lead, and System Administrator Lead,
I will focus on how the technology choice affects:

- Backend structure and maintainability
- API development
- Environment configuration
- Deployment and administration
- Dependency/version management
- Authentication and database integration
- Team development workflow
